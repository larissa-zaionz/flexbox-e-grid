Introdução ao CSS Grid

O que é CSS Grid?

O Griddivide um container em uma grade de linhas e colunas, e você posiciona os itens dentro dessas células. Enquanto o Flexbox trabalha em um eixo (linha ou coluna), o Grid trabalha nos dois ao mesmo tempo.

Ativando Css Grid

.container {
display: grid;
}

Principais Propriedades do Container (Pai) no Grid

  • grid-template-columns — Define a quantidade e o tamanho das colunas (ex.: repeat(3, 1fr)).
  • grid-template-rows — Define a quantidade e a altura das linhas (ex.: 100px 150px).
  • grid-template-areas — Permite montar o layout dando nomes às áreas (ex.: "topo topo" "menu conteudo").
  • grid-auto-rows — Define a altura das linhas criadas automaticamente quando há mais itens do que células.
  • justify-items / align-items — Alinham os itens dentro de suas células, na horizontal e na vertical.
  • place-items — Atalho que combina align-items e justify-items (ex.: place-items: center).
  • justify-content / align-content — Alinham a grade inteira dentro do container, quando ela é menor que ele.

Principais Propriedades dos Itens (Filhos) no Grid

  • grid-column — Define em qual coluna o item começa e termina, ou quantas ocupa (ex.: span 2 ou 1 / -1).
  • grid-row — Define em qual linha o item começa e termina, ou quantas ocupa (ex.: span 2).
  • grid-area — Liga o item a uma área nomeada em grid-template-areas.
  • justify-self / align-self — Sobrescrevem o alinhamento de um item específico dentro da própria célula.
  • place-self — Atalho que combina align-self e justify-self.
  • order — Altera a ordem visual de exibição do item em relação aos outros no código.

Exemplo de CSS grid

.container {
display: grid;
grid-template-columns: 100px 100px 100px; /* 3 colunas de 100px cada */
grid-template-rows: 80px 80px; /* 2 linhas de 80px cada*/
gap: 15px /* define um espaço de 15px de distância de cada caixa/
}
