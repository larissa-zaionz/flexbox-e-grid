O que é o Flexbox?

Flexbox (Flexible Box Layout) é um modelo de layout do CSS para distribuir e alinhar itens dentro de um container em uma dimensão (linha ou coluna), lidando bem com espaço sobrando ou faltando.

Ativando Flexbox

.container {
display: flex;
}

Conceitos Básicos

  • Contêiner Flex (Flex Container): É o elemento pai que recebe a propriedade display: flex (ou codeinline-flex), ativando o contexto flexível para todos os seus filhos diretos.
  • Itens Flex (Flex Items): São os elementos-filhos diretos que estão dentro do contêiner flex.
  • Eixo Principal (Main Axis): É a direção principal na qual os itens são dispostos, definida por flex-direction (row, row-reverse, column, column-reverse).
  • Eixo Transversal (Cross Axis): É a direção perpendicular ao eixo principal.

Principais Propriedades do Contêiner (Pai)

  • display: flex — Transforma o elemento em um contêiner flex.
  • flex-direction — Define a orientação dos itens (linha horizontal ou coluna vertical).
  • flex-wrap — Controla se os itens devem quebrar de linha quando não couberem em uma única linha (nowrap, wrap, wrap-reverse).
  • justify-content — Alinha os itens ao longo do eixo principal (ex.: flex-start, flex-end, center, space-between, space-around).
  • align-items — Alinha os itens ao longo do eixo transversal (ex.: stretch, flex-start, flex-end, center, baseline ).
  • gap — Define o espaçamento exato entre os itens do flexbox.

Principais Propriedades dos Itens (Filhos)

  • flex-grow — Define a capacidade do item de crescer para ocupar o espaço livre disponível (padrão é 0).
  • flex-shrink — Define a capacidade do item de encolher se necessário (padrão é 1).
  • flex-basis — Define o tamanho inicial do item antes que o espaço seja distribuído (padrão é auto).
  • flex — Forma abreviada (shorthand) que combina flex-grow, flex-shrink e flex-basis (ex.: flex: 1 1 auto).
  • align-self — Permite sobrescrever o alinhamento de um item específico no eixo transversal.
  • order — Altera a ordem visual de exibição do item em relação aos outros no código.
